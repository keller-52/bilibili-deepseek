## 为什么用相对路径

`config.yaml` 里 `paths.home: runtime`、`paths.config_dir: config` 都相对仓库根解析，
仓库搬到任何盘都不用改配置。技术方案 §2 里写的 G 盘路径是本机的实际位置。

## 环境问题（已修）

首次会话时 DSH 无法给工作区授权写入（Windows 权限缺“更改权限 / 所有者”），
所有 shell 命令都报 `grantWrite ... Access denied`。用诊断脚本修好后，
备份与回滚脚本在 `<工作区>\..\acl-recovery-bili\`。

`_migrate\` 目录创建时间早于授权、没有继承写权限，所以当时在 DSH 里写不进去；
上移时用的是 `Copy-Item` 而不是 `Move-Item`，新文件才会继承工作区根的权限。
